# Back to 2000 — 1.0 로드맵

현재 작업물을 `0.1.0` 기준선으로 삼는다. 정식 서비스의 핵심 기준은 콘텐츠 양뿐 아니라, 한 곳에서 관리되는 데이터·안전한 운영·출처와 라이선스 관리·접근성·복구 가능한 배포 체계다.

## 0.1 — 탐색 경험 기준선

- 1998~2020년, 연도별 10개 이상의 서비스와 제품
- 수직 연도 탐색기와 이미지 갤러리
- 웹사이트·휴대전화 카테고리 타임라인
- 검색, 상세 스토리, 로컬 추억 컬렉션
- D1 스키마, R2 업로드, 관리자 입력 화면의 기초
- 반응형 UI, 메타데이터, 사이트맵, robots, JSON-LD

현재 가장 큰 구조적 한계는 공개 아카이브가 정적 카탈로그를 읽고 관리자 화면은 D1에 쓰는 두 개의 데이터 경로가 공존한다는 점이다. 0.2에서 가장 먼저 통합한다.

## 0.2 — 단일 콘텐츠 원천

- 정적 카탈로그를 D1 초기 데이터로 이관
- 공개 화면을 `published` 콘텐츠 조회로 전환
- 관리자 CRUD와 초안 → 검수 → 게시 워크플로 구현
- 연도·종류·브랜드·게시 상태용 인덱스와 마이그레이션 확정
- 콘텐츠 삭제/교체 시 R2 객체 정리와 실패 롤백 보강
- 로컬·스테이징·프로덕션 환경 분리

완료 조건: 관리자가 등록·수정·게시한 항목이 코드 배포 없이 공개 사이트에 반영된다.

## 0.3 — 콘텐츠 신뢰성과 편집 도구

- 제품 의의·당시 맥락·후대 영향·상세 사양 필드 정규화
- 공개 화면과 분리된 내부 출처·저작권·라이선스 대장
- 중복, 출시연도, 누락 이미지, 잘못된 모델 자동 감사
- 원본·썸네일·상세 이미지 파생본과 초점/크롭 미리보기
- 웹사이트 화면의 연도별 스냅샷과 비교 보기

완료 조건: 모든 게시 콘텐츠가 출처와 이미지 사용 근거를 내부적으로 추적할 수 있다.

## 0.4 — 계정과 추억 컬렉션

- 사용자 인증 방식 확정 및 계정/세션 구현
- 브라우저 로컬 컬렉션을 D1 계정 컬렉션으로 안전하게 이전
- 좋아요, 즐겨찾기, 비공개/공개 컬렉션
- 개인정보 처리방침, 이용약관, 계정 및 데이터 삭제

## 0.5 — 참여와 운영 안전

- 추억 글·댓글·신고·차단·관리자 검수 큐
- 역할 기반 관리자 권한과 변경 이력
- API 입력 검증, 요청 제한, 업로드 보안 검사
- D1 백업 및 복구 훈련, R2 보존 정책

## 0.6 — 발견과 재방문

- 자동완성 검색, 연도·종류·브랜드 복합 필터
- 관련 콘텐츠와 제품 계보 탐색
- 연도별 인기, 퀴즈, 추억 테스트
- 공유 가능한 컬렉션과 결과 카드

## 0.7 — 품질과 접근성

- Core Web Vitals 예산과 이미지 용량 기준
- 키보드 탐색, 포커스, 명도 대비, 스크린리더 점검
- 저속 네트워크·작은 화면·모션 감소 환경 대응
- 404/500/빈 상태/오프라인 오류 경험 완성

## 0.8 — 배포 자동화와 관측성

- 공개 GitHub 저장소, 브랜치 보호, 리뷰 규칙
- CI에서 lint, build, 테스트, 이미지 감사, D1 마이그레이션 검사
- 오류 추적, 개인정보를 침해하지 않는 분석, 상태 점검
- Cloudflare 스테이징과 프로덕션 분리 및 배포 승인

## 0.9 — 출시 후보

- `backto2000.cloud` 연결, HTTPS·캐시·보안 헤더 확인
- 실제 기기/브라우저 회귀 테스트와 SEO 검사
- 콘텐츠/저작권 최종 감사, 운영 안내서와 롤백 절차
- 제한 베타와 피드백 반영

## 1.0 — 정식 서비스

- 출시 체크리스트와 데이터 백업 확인 후 공개
- 첫 2주 오류율·성능·검색 실패·신고 건 집중 모니터링
- 장애 등급, 대응 담당, 복구 목표를 운영 문서로 유지

## 1.0 출시 게이트

- 보안: 관리자·사용자 권한, 요청 제한, 비밀값 관리 검증
- 데이터: D1 마이그레이션과 백업 복원 시험 통과
- 콘텐츠: 게시 항목의 정확성·이미지 권리 대장 100% 확인
- 품질: 주요 사용자 흐름 E2E, 접근성, 성능 예산 통과
- 법무: 약관·개인정보·저작권·삭제 요청 절차 공개
- 운영: 모니터링·알림·장애 대응·롤백 담당과 절차 확정
