# Back to 2000

1998년부터 2020년까지의 웹사이트, 온라인 서비스, 휴대전화와 디지털 제품을 탐험하는 디지털 타임머신입니다.

현재 기준 버전은 **0.4.1**입니다. D1 기반 익명 추억 컬렉션에 Back to 2000 전용 회원가입과 안전한 로그인 세션, 여러 기기 동기화를 더했습니다.

## 개발

필수 환경은 Node.js 22.13 이상입니다.

```bash
npm install
npm run dev
npm test
npm run lint
npm run quality:catalog
```

운영 환경은 `wrangler.production.jsonc`의 `DB`(D1)와 `MEDIA`(R2) 바인딩을 사용합니다. 마이그레이션은 `npm run cloudflare:migrate`, Worker 배포는 `npm run cloudflare:deploy`로 실행합니다. 배포 관리자 접근은 `ADMIN_EMAILS` 환경값에 쉼표로 구분한 허용 이메일을 설정해야 합니다. 로컬호스트에서는 개발 편의를 위해 관리자 입력 화면을 사용할 수 있습니다.

## 구조

- `app/`: 페이지, SEO, API
- `components/`: 탐색기, 타임라인, 상세 화면, 관리자 UI
- `domain/catalog/`: 카탈로그 원본, D1 조회 저장소와 이미지 매니페스트
- `db/`: 확장 가능한 D1 스키마
- `infrastructure/`: R2와 관리자 권한 경계
- `scripts/`: 이미지 수집·검증 도구
- `docs/ROADMAP.md`: 1.0 정식 배포 계획

## v0.2 운영 경계

정적 TypeScript 카탈로그는 초기 마이그레이션과 품질 감사의 원본으로만 사용합니다. 실제 공개 페이지·검색·사이트맵은 `published` 상태의 D1 데이터만 읽습니다. 기존 검수 이미지는 Worker 정적 자산으로 유지하며, 새 관리자 업로드는 R2에 저장합니다. 수정·게시 승인 워크플로와 역할별 관리자 권한은 다음 편집 도구 단계에서 완성합니다.

## v0.2.1 디자인 원칙

- 한 화면에 하나의 강한 초점을 두고 연도와 제품 이미지를 가장 먼저 보여줍니다.
- 모든 제품·웹사이트 이미지는 잘리지 않는 전시 무대 안에서 표시합니다.
- 베이지·브라운·화이트를 기반으로 네이비와 하늘색을 탐색 상태에 사용합니다.
- 데스크톱의 수직 연표와 모바일의 좁은 화면에서도 같은 탐색 구조를 유지합니다.

## v0.3 글로벌 게임 아카이브

- 1998~2020년마다 장르·산업·플레이 문화에 뚜렷한 영향을 남긴 글로벌 흥행작을 선정합니다.
- 오픈 베타만으로 뭉뚱그리지 않고 실제 공개 단계를 공개 베타·얼리 액세스·정식 출시로 구분합니다.
- 게임 전용 타임라인, 검색, 연도 페이지, 상세 스토리와 관리자 입력을 동일한 D1 카탈로그에 연결합니다.
- 상세 화면은 장르·플랫폼·공개 단계와 흥행의 의의, 이후 장르에 남긴 영향을 함께 설명합니다.

## v0.4 나의 디지털 기억

- 익명 방문자는 기기별 식별 키만 로컬에 보관하고, 실제 컬렉션과 반응은 D1에 저장합니다.
- 제품과 서비스에 `써봤어요`, `기억나요`, `갖고 싶었어요` 반응을 남길 수 있습니다.
- 컬렉션 화면은 선택한 연도와 브랜드를 분석해 개인의 디지털 전성기 결과를 보여줍니다.
- 기존 로컬 컬렉션은 첫 접속 시 새로운 D1 컬렉션으로 자동 이전됩니다.
- 외부 소셜 계정 없이 전용 아이디와 비밀번호로 가입하며, 비밀번호는 개별 salt를 사용한 PBKDF2-HMAC-SHA256과 D1 밖의 Worker secret HMAC pepper로만 저장합니다.
- 로그인하면 현재 기기의 익명 컬렉션이 회원 컬렉션으로 자동 병합되고 여러 기기에서 동기화됩니다.
- 계정 화면에서 표시 이름과 공개 준비 상태를 관리하고, 비밀번호 확인 후 계정과 컬렉션을 삭제할 수 있습니다.
